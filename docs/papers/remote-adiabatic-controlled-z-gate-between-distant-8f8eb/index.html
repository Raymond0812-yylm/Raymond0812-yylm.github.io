远距超导量子比特间的远程绝热控制-Z 门

Remote Adiabatic Controlled-Z Gate between Distant Superconducting Qubits

量子硬件平台 🏭 制造调度 日报精选 · 2026-09-18

核心内容

单芯片超导量子处理器正逼近布线、串扰与制造良率的物理瓶颈，"模块化多芯片 + 芯间远程纠缠"是 IBM（量子网状互联路线）等主流厂商公认的扩展路径。现有远程双比特门方案多依赖可调耦合器或光子中介，架构复杂。BAQIS 团队提出并数值验证了一条克制的替代路线：直接用一段多模同轴线缆连接两枚频率可调超导比特，利用绝热脉冲实现远程 CZ 门，无需任何额外可调耦合器，保持电路架构极简。仿真计入十个驻波模式后，30 cm 线缆下门错误率低至 4.71×10⁻⁷（376.7 ns，无退相干极限），且对比特频率涨落与毫米级线…
