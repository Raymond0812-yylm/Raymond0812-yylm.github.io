图表示学习助力QAOA参数可迁移性研究

Graph representation learning for parameter transferability in quantum approximate optimization algorithm

量子近似优化 变分量子算法

核心内容

最优QAOA参数在不同MaxCut实例间的可迁移性是降低训练开销的关键。Safro团队用图表示学习刻画局部性质(子图光锥类型等)与参数聚类的关系,实现跨实例参数迁移的成功率预测。该工作把"经典图特征预测量子算法行为"落为可操作方法,与GNN+量子优化的混合研究路线高度相关。

Abstract The quantum approximate optimization algorithm (QAOA) is one of the most promising candidates for achieving quantum advantage through quantum-enhanced combinatorial optimization. Optimal QAOA parameter concentration effects for special MaxCut problem instances have been observed, but a rigorous study of the subject is still lacking. Due to clustering of optimal QAOA parameters for MaxCut, successful parameter transferability between different MaxCut instances can be explained and predicted based on local properties of the graphs, including the type of subgraphs (lightcones) from which graphs are composed as well as the overall degree of nodes in the graph (parity). In this work, we apply five different graph embedding techniques to determine good donor candidates for parameter transferability, including parameter transferability between different classes of MaxCut instances. Using this technique, we effectively reduce the number of iterations required for parameter optimization, obtaining an approximate solution to the target problem with an order of magnitude speedup. This procedure also effectively removes the problem of encountering barren plateaus during the variational optimization of parameters. Additionally, our findings demonstrate that the transferred parameters maintain effectiveness when subjected to noise, supporting their use in real-world quantum applications.
