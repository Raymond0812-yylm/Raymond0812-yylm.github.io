UAV-enabled multicast transmission is pivotal for low-altitude economy networking, but is fundamentally constrained by dynamic channel availability and fluctuations stemming from UAV mobility. Efficient integration of fragmented spectrum resources spanning multiple frequency bands for opportunistic multicast transmission not only elevates resource utilization but also broadens service scalability. Nevertheless, the fragmented spectrum exhibits strong frequency selectivity, compounded by the max-min objective inherent to multicast broadcast services (MBS) and the nonlinear channel aggregation characteristics, which collectively render the resource allocation problem an intricate max-min nonlinear combinatorial optimization problem. To tackle this challenge, this paper proposes an artificial general intelligence (AGI)-driven deep resource allocation algorithm for spectrum aggregation (SA)-enabled UAV-MBS systems, capable of accommodating diverse UE demands and flexible resources. A pointer network-based neural combinatorial optimization (NCO) solver, integrated with a self-reference reinforcement learning framework, is employed to achieve probability-driven sequential resource selection. Sensitivity analysis and stepwise decomposition are conducted to evaluate the effectiveness of the trained network, providing interpretability and deeper insights into the NCO solver.
