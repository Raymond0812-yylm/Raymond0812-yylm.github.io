可扩展逻辑量子比特

Scalable logical qubits

领域综述与交叉前沿 日报精选 · 2026-09-20

核心内容

年以来，"逻辑量子比特"成为硬件军备竞赛的新话术：Quantinuum/微软/IBM/谷歌各自展示逻辑比特寿命超越物理比特、双逻辑比特门保真度超越物理门、乃至小规模纠错算法演示——但各家口径不一，"逻辑比特"一词被同时用来指代十几个物理比特勉强维持的单个纠错单元，和数百逻辑比特上的容错计算，横向比较近乎不可能。三位来自不同技术阵营的权威学者试图终结这种混乱：为"能支撑 utility-scale 计算的逻辑量子比特"给出可操作的定义与度量维度。
