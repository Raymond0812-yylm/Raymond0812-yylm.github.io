量子单层感知机的变分算法

A Variational Algorithm for Quantum Single Layer Perceptron

量子计算×人工智能 量子-经典混合优化

核心内容

提出量子单层感知机 qSLP 的变分算法:设计执行线性组合的量子线路,产生与经典感知机输出等价的量子态,是"从最简单的神经网络单元开始重建量子机器学习"的代表性尝试,代码开源。

原始摘要

展开 / 收起英文摘要(共 424 字符)

Hybrid quantum-classical computation represents one of the most promising approaches to deliver novel machine learning models. In this work, we propose a novel variational algorithm for quantum Single Layer Perceptron (qSLP), which allows producing a quantum state equivalent to the output of a classical single layer perceptron. The work also designs a quantum circuit to perform linear combinations in quantum computation.
