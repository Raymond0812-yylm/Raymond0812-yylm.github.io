用增强型量子求解器在 NP 完全问题上实现标度优势的证据

Evidence of scaling advantage on an NP-complete problem with enhanced quantum solvers

领域综述与交叉前沿 日报精选 · 2026-09-03

核心内容

量子优势（quantum advantage） 是 NISQ（含噪中等规模量子）时代的核心里程碑。但现有"量子优越性"演示（如随机线路采样）针对的是人为构造、无实用价值的问题；而对真正经典难解（NP 完全）且有用的组合优化问题，量子算法始终未能展示出对最好经典求解器的优势。在缺乏严格复杂度证明的前提下，论文采用务实的替代判据——标度优势（scaling advantage）：随着问题规模增大，量子方法的资源需求增长指数底数若小于最好经典方法，即视为量子优势的经验证据。
