量子增强的多目标优化（框架 QEMOO）

多目标组合优化（Multi-Objective Combinatorial Optimization, MOCO）广泛存在于工程设计、物流调度、金融投资与科学发现等领域，需要在相互冲突的目标之间寻找帕累托（Pareto）最优解集。其单目标版本往往已是 NP-hard，多目标化之后难度更高，精确的多目标整数规划求解器随规模增长迅速失效。

用增强型量子求解器在 NP 完全问题上实现标度优势的证据

量子优势（quantum advantage） 是 NISQ（含噪中等规模量子）时代的核心里程碑。但现有"量子优越性"演示（如随机线路采样）针对的是人为构造、无实用价值的问题；而对真正经典难解（NP 完全）且有用的组合优化问题，量子算法始终未能展示出对最好经典求解器的优势。在缺乏严格复杂度证明的前提下，论文采用务实的替代判据——标度优势（scaling advantage）：随着问题规模增大，量子方法的资源需求增长指数底数若小于最好经典方法，即视为量子优势的经验证据。

基于量子优化算法的能源互联网路由

能源互联网（Energy Internet, EI） 是为实现可再生能源与电网深度融合而提出的新一代能源系统架构。在 EI 中，能量以"数据包"式的形式在网络节点间路由传输，其核心运筹问题之一是能效最优路径选择（energy-efficient path selection）——在满足需求的前提下，选择传输损耗最小、能效最高的能量路由方案。该问题被证明是 NP-hard 的：随着网络规模增长，经典精确算法的计算代价急剧上升。
