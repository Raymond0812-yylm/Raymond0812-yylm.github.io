    从量子谱特征学习图的结构平衡度

    符号图（signed graph）的结构平衡（structural balance）是图论与社会网络分析的经典概念：把社会关系网络中的"朋友/敌人"连边抽象为正/负号，Harary 定理告诉我们，平衡图可划分为内部互友、外部互敌的集团；而现实网络往往不平衡，其偏离程度可用阻挫指数（frustration index，即最少需要删掉多少条负边才能使图平衡）来量化——这是一个 NP 难的组合不变量，也是自旋玻璃物理中"阻挫"的直接图论对应物，经典方法只能靠启发式近似。

    量子重叠间隙性质与量子超图最大割问题的算法难度

    重叠间隙性质（Overlap Gap Property, OGP） 是经典平均情形复杂性理论的主力工具：对随机组合优化问题（如随机 Max-Cut、k-SAT），若近优解在构型空间中"聚类且互斥"（任意两个近优解重叠度要么高要么低、不存在中间地带），则一大类"稳定"算法（对输入扰动不敏感的算法，涵盖局部算法、低深度电路等）在平均情形下无法逼近最优。OGP 已成功解释了为何许多问题在大规模随机实例上算法性能集体停滞。
