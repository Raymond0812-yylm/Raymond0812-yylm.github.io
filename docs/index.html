    求解最小颜色数图着色问题的量子-经典方法

    最小色数图着色（求 chromatic number）是经典 NP 完全问题，直接映射调度、寄存器分配、频率指配等真实负载；经典精确算法在大图上不可行，而直接套用 Grover 搜索需要预先知道解的个数。本文的组合方案：用随机化 Grover 搜索（在解数未知时仍可工作的变体，保持二次加速）判定"给定 k 种颜色是否存在合法着色"，外层用经典二分搜索收缩 k 的区间，直至锁定最小色数。
