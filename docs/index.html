#2 量子近似优化 arXiv:2609.04462

刻画贫瘠高原的表示论框架

贫瘠高原（barren plateau）——代价函数梯度方差随系统规模指数消失——是包括 QAOA 在内一切变分量子算法可扩展性的根本威胁。近年最有力的分析工具是基于动力学李代数（DLA）的李代数方法（本专栏 09-06 期主推的 QAOA 表达能力约简即属此谱系），但它有一个关键限制：要求初态或观测量本身落在电路生成的 DLA 内，否则工具失效。

#3 量子硬件平台 arXiv:2609.04459

三维量子比特控制带来的高效量子纠错

高码率 qLDPC 码（如 [[144,12,12]] 双变量自行车码）相对表面码可大幅降低比特开销，但其优势兑现取决于能否高效实现非局域的校验子提取——这恰是二维平面架构的短板。本文研究在中性原子平台的原生三维（3D）几何中执行该码：保持码不变，仅比较平面排布与 3D 排布。核心结果：以"单位光学视场内的逻辑比特密度"为度量，3D 嵌入的面积逻辑密度约为平面布局的 4 倍、表面码基线的 42 倍；同时校验子提取时间缩短约 2 倍（原子搬运次数更少、传输距离更短）。
