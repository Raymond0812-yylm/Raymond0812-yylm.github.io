二、研究背景与动机

配电网重构（Distribution Network Reconfiguration, DNR）是电力系统运行中的经典 NP-hard 组合优化问题：通过改变分段开关与联络开关的开合状态调整网络拓扑，在维持辐射状（radiality）与连通性约束的前提下最小化有功线损。开关组合随规模指数增长，工业界长期依赖启发式规则、混合整数规划与专家经验交替求解。量子优化近年多次尝试进入这一领域（含本报 10-04 提及的同联盟 LR-QAOA + MISOCP 两阶段工作），但暴露出三个共性痛点：其一，约束处理——把辐射性约束写成 QUBO 罚项后，大量采样结果不可行，需修复或整批丢弃，量子比特预算被浪费在非法解上；其二，变分参数负担——QAOA 类算法的外环经典优化成本高、易陷局部最优，在工业时效约束下很不划算；其三，与公用事业既有交流潮流（ACPF）工具链的衔接缺位。本文的动机正是三痛齐治：设计一个"任何测量结果都可解码为合法辐射状配置"的编码，配合一个无需变分参数训练的量子子程序（量子虚时演化 QITE），让量子方法成为工业求解流程中即插即用的组件。

三、核心方法与技术路线

  1. 分支交换编码（branch-exchange encoding）：以生成树上的"环支路交换"为原子操作编码重构动作，将问题映射为量子寄存器上的哈密顿量，使得每一个寄存器测量结果都唯一解码为一个合法辐射状配置——可行性内建于编码本身，而非事后罚项或修复。
  2. 经典代理模型 + 暖启动：用经典求解得到的 ACPF 标签拟合损失代理模型（surrogate），既为量子子程序提供暖启动初态，又把工业潮流知识注入搜索过程，显著压缩量子需探索的空间。
  3. 迭代暖启动 QITE：以 QITE 模拟非酉虚时演化——天然朝低能态单调移动、无变分参数外环；迭代地用当前找到的最优配置更新暖启动，形成"量子演化—经典评估—再暖启动"的混合循环，在固定求解与采样预算内返回历史最低损配置。
  4. 规模化支撑：提出两种问题规模缩减方法（问题分解/变量归并），使框架可部署到更大规模的实际配电网。

四、主要实验/理论结果

在 10 个测试案例（7 个标准配电网基准 + 3 个改造案例）上：6 个案例直接达到最小损耗配置，其余 4 个落在参考最优解的 0.2%–2.18% 以内。结果表明，"约束保持编码 + 暖启动迭代 QITE"的组合能在开关组合指数级增长的现实规模公用事业问题上稳定给出可用解；量子子程序部分线路结构规整、对 NISQ 设备（如离子阱）友好，经典部分与既有 ACPF 工具链无缝衔接，端到端流程可直接嵌入电网运行人员的求解器队列。

五、对研究领域的意义与启示

其一，"约束保持编码"是本文最大亮点，与本报 09-18（Constrained QAOA/表达力分析）、09-02（MWIS kernel）一脉相承的"把可行性放进编码/ansatz 而不是罚项"路线再添一员，而且是在真实工程负载上完成验证——对 QUBO 罚项法这一量子优化落地最常被诟病的软肋，给出了系统性替代方案。其二，QITE 作为 QAOA 的"无参数"替身在组合优化应用中拿出了有说服力的案例：省掉变分外环不仅降低成本，也让算法行为更可预期，这对有实时性要求的电网运行场景尤为关键。其三，产业信号值得细读：欧洲最大电网运营商之一 E.ON 与 Quantinuum 的系列产出（本文 + 两阶段 QAOA 工作）表明，工业界对量子优化的投入并未因"经典侧依然很强"的舆论而停步，只是越来越以"与经典工具链协作、能算清端到端账"为前提——这与本报连续四日追踪的"端到端核算"主线（袁骁结构化编码→倾斜行走分离→DQI 分离→Katzgraber 资本侧回声）完全同频：量子优化正在从"证明能赢"转向"证明好用、好接入、好算账"。
