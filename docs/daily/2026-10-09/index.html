论文一：给"量子优化优势"立复杂度标尺——定义 BQ-APX 类层级，并借分解与离散对数给出首批量子-经典近似保证分离

一、论文基本信息

项目 内容

二、研究背景与动机

经典近似复杂度理论早已为"多项式时间内能保证多好的解"建立了完整语言：APX 区分固定近似比可达与不可达，PTAS 允许逼近任意固定精度，FPTAS 进一步要求运行时间对精度倒数也是多项式；其随机化对应类 R-APX/R-PTAS/R-FPTAS 同样成熟。然而量子计算的对应语言一直缺席——QAOA、量子退火、量子-经典混合算法在实践中被大量启发式使用：在若干基准实例上跑出高分，并不构成任何最坏情况保证；反过来，"量子算法"这个词在实践中过于宽泛，从态制备、测量到经典后处理，哪些开销应计入"运行时间"也从未被严格圈定。这导致"量子计算能否改进组合优化的近似保证"这一核心问题，长期停留在经验比较层面，无法进入复杂度理论的话语体系。

本文的动机正是补上这块基石：为有界误差量子计算定义与 APX/PTAS/FPTAS 平行的近似复杂度类，并首次给出严格的包含关系（层级定理）与量子-经典分离例子。作者的选择颇具巧思——分离并不寄望于 MaxCut 这类"硬骨头"，而是把 Shor 算法的代数优势（分解、离散对数）编码进优化问题的近似保证：若经典随机算法能在这些问题上给出看似很弱的近似保证，就会导出高效的分解或离散对数算法——从而在标准假设下排除经典可能性，而量子侧由 Shor 算法直接给出精确解。

三、核心方法与技术路线

  1. 定义量子近似类 BQ-APX / BQ-PTAS / BQ-FPTAS：成员资格要求一个一致的量子算法，对每个输入都以至少 2/3 概率返回一个达到声称近似比的可行经典解；问题的目标函数值必须可经典高效计算；且"运行时间"采用全成本口径——参数选择、初态制备、量子演化、测量、解码与重复采样全部计入。这一口径堵住了"把开销藏进预处理或后处理"的漏洞，使类定义对 QAOA 类混合算法同样可检验。
  2. 条件层级定理：在对数、多项式、指数三类近似因子下建立量子近似类之间的严格包含关系；在 NP ⊄ BQP 的标准假设下，层级是严格的——即"允许更差的近似比确实换到更强算力"在量子世界中同样成立。
  3. 基于代数问题的条件分离构造：设计两类"桥接问题"。其一是 Certified Maximum Order（带认证的最大阶问题）：由 Shor 算法可得精确量子算法；反之，任何保证逆多项式近似比的随机多项式时间经典算法都可转化为随机多项式时间的整数分解——在分解不被认为随机多项式可解的假设下，经典侧被排除。其二是 Discrete-Logarithm Fitting（离散对数拟合）：量子侧同样精确可解；经典侧存在确定性的 1/2 近似算法，但对 1/2 的任何固定改进都会给出 safe-prime 离散对数的随机多项式算法——形成"经典能做到 1/2、量渡能做到精确、中间地带条件性不可达"的精细分离。
  4. 对启发式方法的定位：文中明确指出，QAOA 等方法的高基准分数不构成上述类的成员资格证明——复杂度保证要求对每个输入的成功承诺，而非平均意义或选定实例上的表现。

四、主要理论结果

  • 量子近似复杂度类体系成立：BQ-APX/BQ-PTAS/BQ-FPTAS 在有界误差量子计算下良定义，且与经典 R-APX 体系形成自然对照（随机经典类是量子类的子类）。
  • 严格层级：假设 NP ⊄ BQP，对数—多项式—指数近似因子对应的量子类形成严格包含链，量化了"近似松弛换算力"的交换率。
  • 量子-经典近似分离的第一批具体实例：Certified Maximum Order 与 Discrete-Logarithm Fitting 在显式复杂度假设下分别展示"量子精确可解 vs 经典条件性不可近似"与"经典卡在 1/2 vs 量子精确"两种形态的差距——证明量子计算可以改进最坏情况近似保证，而不只是加速求解。
  • 开放问题被精确陈述：MaxCut、MaxSAT 等 QAOA 主战场的量子-经典近似差距仍然开放——本文把这一悬而未决的核心问题从"跑分之争"升级为定义良好的复杂度问题。

五、对研究领域的意义与启示

这篇论文为整个"量子求解组合优化"方向补上了理论坐标系。过去十年 QAOA 社区的论证方式主要是两层：小实例基准跑分（经验层）与特定图族上的解析性能（如 SK 模型能量密度），但"量子算法在近似保证意义下严格更强"从未有过类级别的框架可陈述。Hadfield 的工作让三个长期模糊的问题变得可判定：其一，什么样的证据才算"量子优化优势"——答案是被纳入 BQ-APX \ R-APX 这类分离，而非任何基准分数；其二，量子近似类的边界在哪里——层级定理给出了近似因子与算力交换的基本定律；其三，下一步该攻什么——把分离从代数编码问题推进到自然优化问题（MaxCut/MaxSAT），这是本文清晰立起的靶子。

对混合算法社区而言，全成本口径的运行时间定义也是一种纪律：态制备、测量、解码全部计入后，许多"纸面优势"将重新接受审视——这与近期 QAOA 端到端复杂度分析（本报 10-04 袁骁团队端到端加速、10-07 变分训练 NP-hard）构成同一股"把量子优化的账算全"的方法论潮流。对硬件路线图（如今日行业动态中 DARPA QBI 的"算力价值超过成本"验证标准）而言，本文提供的正是其理论侧的镜像：优势必须在最坏情况保证的意义下被定义和检验。可以预期，BQ-APX 框架将成为后续量子近似算法工作的标准引用点之一。

二、研究背景与核心方法

擦除偏置（erasure bias）是超导平台通往低逻辑错误率的关键路线之一：让错误集中发生在"可检测的时间/位置"上，纠错码便可利用这一结构大幅降本。但双轨（dual-rail）编码等擦除方案长期面临两难——强驱动虽然能保护编码免受低频噪声侵扰并激活快速参数化交互，却引入驱动诱导退相与漏率等寄生过程。本文的突破口是一个频率选择性的观察：超导 Kerr 振子（transmon 区）对电荷驱动的频率敏感性随驱动频率与幅度二次增长——对 1/f 低频电荷噪声弱敏感，对接近 1 GHz 的快驱动却强耦合。据此，团队用亚 GHz 电荷驱动一举两得：既激活快速参数化门，又对编码比特形成动态保护，绕开了"快"与"稳"的传统取舍。

三、主要结果与意义

实验在三个层面给出完整链条：单个 Kerr 振子 82 ns 内完成冷却与复位、残余布居降至 0.7%（低于 2.5% 的热稳态布居）；两个 Kerr 振子构成双轨比特，实现逻辑控制与动态保护，擦除偏置接近四倍；仅用一次末端擦除检查，即实现每 Clifford 错误率 5.6×10⁻⁴、门长仅 25 ns，后选择后进一步降至 1.5×10⁻⁴。这一"快门 + 高擦除偏置 + 低错误率"的组合直接对标猫态比特、双轨腔比特等主流擦除路线，且 25 ns 门长意味着相同相干预算内可容纳更多门操作。它与本报昨日行业动态中 D-Wave 双轨 DRQ 模拟器、以及持续升温的"擦除感知纠错码"设计浪潮同频——擦除型超导比特正在从单点演示走向可组合的工程路线，为未来容错架构的错误预算提供了新的硬件侧选项。

二、研究内容与意义

可微量子架构搜索（DQAS）把神经网络架构搜索的松弛技巧搬到量子线路上：让候选门集合的权重可微，端到端自动设计变分量子优化算法的线路结构，是"让算法自己长出来"的代表性框架。但它的实用化瓶颈在测量——优化过程中每一步都要为大量候选线路采样估计梯度，真机执行成本高昂。本文证明：对一大类组合优化问题与常用旋转门参数化，同一批测量结果可被复用来重构多个架构候选的梯度，从而在不改变优化目标的前提下显著削减测量需求；该测量缩减方案附有理论推导，并在 3-SAT 与 MaxCut 基准上实验验证——梯度测量成本降低约 39–41%，经典后处理开销可忽略。

这项工作的分量在于它打击的是 DQAS 落地真机的第一瓶颈（测量预算），而非又一个跑分改进；四成的降本对 NISQ 时代按 Shots 计费的硬件执行是实打实的成本工程，也与本报持续关注的"组合优化 + 机器学习杂交"路线（学习型 QAOA 参数、神经架构搜索式 ansatz 设计）形成互补。对致力于把变分量子算法推向实用的研究者，这是一个即插即用的省钱技巧——代码已开源，可直接接入现有 DQAS 流水线。
