论文一：锐度即采样预算——Pauli 压缩编码的 MaxCut 训练理论在 IBM Heron 真机上全面重校准

一、论文基本信息

项目 内容
英文标题 Shot- and Noise-Aware Pauli Correlation Encoding for Max-Cut Experiments on IBM Heron Quantum Processor
中文标题 面向 IBM Heron 量子处理器 MaxCut 实验的采样与噪声感知 Pauli 关联编码
作者列表 Achraf Boussahi（单作者工作）
发表平台 arXiv 预印本（quant-ph）
arXiv 编号 2610.19544（2026-10-14 提交，v1）
原文链接 https://arxiv.org/abs/2610.19544

二、研究背景与动机

QAOA 直接求解 $m$ 个二元变量的组合优化问题需要 $m$ 个量子比特和足以铺开问题图连通性的深电路，这是 NISQ 硬件难以承受的。Pauli 关联编码（Pauli Correlation Encoding, PCE） 是近两年 IBM 生态主推的破局思路（IBM Quantum 已提供官方 Qiskit 教程，衍生工作覆盖预算约束割、机组组合调度等）：把 $m$ 个二元变量编进 $k$-体 Pauli 关联子的符号里，只需 $n=O(m^{1/k})$ 个量子比特，再以参数化电路在"锐度为 $\alpha$ 的松弛损失"上训练——极限 $\alpha\to\infty$ 即回到原问题。此前的最强调度（sharpening schedule，逐步增大 $\alpha$ 的训练日程）在 G-set 基准上成绩亮眼，但全部以精确期望值做基准测试。

本文动机正戳这一软肋：真实量子计算机只能从**有限 $S$ 次采样（shots）**中估计关联子符号。作者要回答两个问题：为什么用精确期望值调出的调度在真实采样预算下优势尽失？以及，能否写出一个把采样预算与器件噪声都纳入训练理论的调度，并在真机上验证？

三、核心方法与技术路线

  1. 核心定理：锐度是被隐藏的采样预算。从 $S$ 次采样估计的关联子期望符号 $\mathrm{erf}(c\sqrt{S/2})$ 与 $\tanh(0.851\sqrt{S},c)$ 之差不超过 0.019——因此当 $\alpha = 0.851\sqrt{S}$ 时，松弛损失的边项近似等于（差一常数）"从 $S$ 次采样解码所得期望割值的 −2 倍"。这一恒等式把"损失锐化日程"与"采样预算分配"严格挂钩：训练理论从此有了物理记账单位。
  2. 失效诊断与 shot-aware 调度：既然锐度等价于预算，用精确期望值（相当于 $S\to\infty$）调出的激进锐化日程，在有限预算下就是"超支"的——这解释了已发表调度的失效机理。由此导出新调度：最终锐度直接由目标采样预算设定。
  3. 噪声的预算换算：器件噪声把关联子整体阻尼一个因子 $s$，其效果精确等价于把有效预算缩为 $s^2 S$；真机调度据此取 $\alpha \simeq 0.65,s\sqrt{S}$，且 $s$ 与偏移量可在同图其他电路上校准后直接迁移预测。

四、主要实验/理论结果

  1. 仿真（G-set 基准）：5 个 G-set 图、800 个变量仅用 13 个量子比特承载；在 150 组配对比较中，shot-aware 调度在其目标预算下全胜所有已发表调度（$1.6\times10^4$ shots）；$10^3$ shots 下的增益主要来自适时关闭正则化项。经典 bit-swap 局部搜索之后，它在 $1.6\times10^4$ shots 下仍是平均最优。
  2. 真机（IBM Heron 处理器 ibm_fez）：曾产出 G-set 最佳成绩的全对角 ansatz 编译后需 835 个 CZ 门，真机解码结果退化为随机割——深电路被噪声彻底淹没；而作者的 96 CZ 硬件原生电路（仿真中训练、按 $\alpha\simeq0.65,s\sqrt{S}$ 锐化）保留了最优已知割值的 0.919。
  3. 预测能力：在同图其他电路上校准的阻尼因子与偏移，对新电路在 $10^3$ shots 下的解码割值预测误差仅 0.002——噪声换算不是拟合技巧，而是可迁移的定量规律。

五、对研究领域的意义与启示

  1. 方法论修正具有普适性："任何用精确期望值调出的变分算法，在有限采样下都需要重新校准"——本文给出的 erf–tanh 桥接与预算换算工具，可直接迁移到其他基于解码/挤压类损失的压缩编码框架。变分量子优化的理论评价标准应从"期望值世界的收敛"转向"采样-噪声真实世界的输出质量"。
  2. 压缩编码 + 硬件原生浅电路是 NISQ 落地的可行组合拳：800 变量压到 13 比特、96 个双比特门保留 92% 最优割——这条"少比特、浅电路、真机验证"的路线比"等大规模容错硬件"务实得多；同时 835-CZ 电路的全灭也再次标出当前硬件深度红线。
  3. 对基准体系的提醒：论文一与昨日报告的"经典下界抬升"互为补充——量子侧的军备竞赛不只是"更深 ansatz"，还有"更聪明的编码与预算理论"；今后评估量子优化进展，采样预算与器件噪声必须进入报告口径。

论文二：QAOA 电路的第二职业——Montanaro 团队用浅层 IQP/QAOA 电路攻图同构判别

一、论文基本信息

项目 内容
英文标题 Testing graph isomorphism using simple quantum circuits
中文标题 用简单量子电路检验图同构
作者列表 Samuel Beasley, Ashley Montanaro（布里斯托大学；Montanaro 为量子算法领域知名学者）
发表平台 arXiv 预印本（quant-ph）
arXiv 编号 2610.19962（2026-10-14 提交，v1）
原文链接 https://arxiv.org/abs/2610.19962

二、研究背景与方法

图同构问题（判断两图是否仅差一个顶点重排）的计算复杂性至今悬而未决，是经典复杂度理论的著名空白。本文换一个提问角度：为图定制的浅层量子电路（IQP 与 QAOA）的输出分布，究竟编码了多少图结构信息？ 作者证明：合适的 IQP/QAOA 构造可经多项式次数采样重构原图；当 QAOA 能量差为零、能量判据失效时，Hamming 权重分布仍能区分图对；再对输出的 ZZ 关联子矩阵施加图不变量（图谱），并新造基于"Hamming 权重分区内概率多重性"的更细不变量。

三、主要结果与意义

QAOA 深度 $p=2$ 时，图谱不变量在多达 18 顶点的全部 10,486 对同谱正则图对上数值判别成功；IQP 的多重性不变量则区分了测试中每一对非同构图。作者还对 $\theta=\pi/2$ 与 $\theta=\pi/4$ 给出 IQP 输出分布的精确图论刻画。意义有二：其一，浅层量子电路远比想象中"知道"更多图论结构——QAOA 不只可以做优化，还可以做结构探测器；其二，留下一道干净的理论开放题：这些信息能否对一般图同构被高效提取。对组合优化社区而言，这是"QAOA 电路 = 可编程图特征提取器"这一认知边界的正式测绘。

论文三：把反思写进权重——EPOCH 让 LLM 自动启发式设计从提示工程走向经验内化

一、论文基本信息

项目 内容
英文标题 EPOCH: Coverage-Aware Evolution with Experiential Preference Optimization for LLM-based Automated Heuristic Design
中文标题 EPOCH：面向 LLM 自动启发式设计的覆盖感知进化与经验偏好优化
作者列表 Oguzhan Gungordu, Ayse Tursucular, Siheng Xiong, Faramarz Fekri（Georgia Tech 团队）
发表平台 arXiv 预印本（cs.AI / cs.CL）
arXiv 编号 2610.17379（2026-10-12 提交，v1）
原文链接 https://arxiv.org/abs/2610.17379

二、研究背景与方法

LLM 自动启发式设计（AHD）让 LLM 在进化搜索中为组合优化问题（COP）生成启发式，但现有框架有两个天花板：生成器要么被冻结、只在标量适应度上微调（看不见"每个启发式覆盖了哪些实例"）；反思式改进只停留在 prompt 里，从未进入生成器权重。EPOCH 的做法：把实例覆盖率设为进化目标——父代选择、算子分配、停滞恢复全部优化启发式集合对训练实例的联合覆盖，从而返回一组互补的启发式集成；同时以"经验偏好优化"让生成器内化反思——教师 LLM 对生成的启发式给出自然语言洞察，生成器带着洞察重生成，改进对进入 DPO 偏好优化，再由反思自蒸馏（RSD）项把"排名上更好"强化为"更可能自己生成出来"，增益随搜索长程累积。

三、主要结果与意义

在多个 COP 与多个开源 LLM 底座上，EPOCH 的启发式集成全面优于推理-only 与已微调基线，且跨问题规模泛化。意义：其一，AHD 的进化增益第一次沉淀为模型参数而非上下文记忆，搜索经验可以复用、可以迁移，这是"LLM 优化器"从工具走向方法的关键一步；其二，与量子侧对照鲜明——经典 LLM 启发式正以周为单位快速迭代，量子优化的实用化叙事必须把这条快速长高的经典水位线计入竞争格局。
