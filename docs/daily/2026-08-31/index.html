二、研究背景与动机

能源互联网（Energy Internet, EI） 是为实现可再生能源与电网深度融合而提出的新一代能源系统架构。在 EI 中，能量以"数据包"式的形式在网络节点间路由传输，其核心运筹问题之一是能效最优路径选择（energy-efficient path selection）——在满足需求的前提下，选择传输损耗最小、能效最高的能量路由方案。该问题被证明是 NP-hard 的：随着网络规模增长，经典精确算法的计算代价急剧上升。

在"双碳"目标与高比例可再生渗透的背景下，该问题的规模与实时性要求不断提高，传统方法（如 Dijkstra 最短路径算法、数学规划求解器）在大规模、多约束场景下面临可扩展性瓶颈。量子计算——尤其是量子退火（Quantum Annealing）与量子近似优化算法（QAOA）——为组合优化问题提供了新的求解范式：将路径选择问题映射为 QUBO / Ising 模型后，可借助量子硬件或量子启发式求解器进行搜索。本文正是这一思路在能源互联网路由场景中的系统性落地与实证评估。

三、核心方法与技术路线

本文的技术路线遵循"问题建模 → 量子映射 → 多求解器验证 → 经典-量子对比"的完整闭环：

  1. QUBO / Ising 哈密顿量建模：提出一种面向能源路由的创新性二次无约束二元优化（QUBO）与 Ising 哈密顿量数学表达，将 EI 中能量高效路径选择问题编码为量子优化硬件可直接处理的能量最小化形式；
  2. 量子门电路优化（QAOA 路线）：基于 Qiskit 框架的 Sampler Primitive 实现 QAOA 求解，并使用 NumPyEigenSolver 作为基准特征值求解器；
  3. 量子退火 / 量子启发式路线（D-Wave 生态）：使用 Ocean 工具链中的 Exact Solver（精确求解器）、Tabu Sampler（禁忌搜索采样器） 与 Simulated Annealing（模拟退火采样器） 求解同一 QUBO 模型；
  4. 经典基线对比：以 Dijkstra 算法及基于数学规划的优化方法作为经典参照，形成系统的量子-经典混合对比评估框架；
  5. 案例研究：在 9 节点与 30 节点两个能源互联网测试网络上验证模型的正确性与可扩展性。

四、主要实验结果

  • 正确性：基于所提 QUBO/Ising 模型，各量子（及量子启发）求解方法的仿真结果与精确解（Exact Solver）完全一致，验证了建模的正确性；
  • 性能对比：在当前规模下，经典方法（Dijkstra 等）的运行时间仍短于量子方法——这一诚实的负面结果对领域内的"量子优势"预期具有重要的校准意义；
  • 量子方法内部：D-Wave 模拟退火采样器（Simulated Annealing） 在所有量子类方法中运行时间最短，说明在 NISQ 时代，量子启发式退火方法在实用性上先于门电路 QAOA；
  • 可扩展性：9 节点 → 30 节点的规模扩展实验表明所提建模方法具备进一步放大的潜力。

五、对研究领域的意义与启示

  1. 应用领域拓展：这是量子组合优化技术在能源互联网/智能电网这一国家重大基础设施场景的较新落地工作，为"量子计算赋能行业优化"提供了从建模到求解的完整参考模板；
  2. 建模方法论价值：论文给出的能源路由 QUBO/Ising 形式化表达，可复用于能源调度、网架规划、电力市场出清等相邻 NP-hard 问题，是"实际问题 → 量子模型"转化的范例；
  3. 量子-经典公平对比范式：论文同时使用 QAOA（门电路路线）与量子退火（D-Wave 路线）并诚实地报告经典方法在运行时间上的优势，为 NISQ 时代"量子何时真正有用"提供了清醒的实证参照；
  4. 对混合框架研究的启示：结果显示模拟退火等量子启发方法当前最具实用价值，提示近期研究应更多关注"经典预处理 + 量子启发搜索 + 浅层 QAOA 精修"的混合优化架构，而非单纯追求全量子求解。
